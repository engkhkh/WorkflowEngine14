# Workflow ERP - React Native (Expo)

    npm install
    npx expo start          # press a for Android, i for iOS, or scan the QR code with Expo Go
    npm run typecheck

Android emulator reaches the backend at `http://10.0.2.2:5000` (default on the login screen); a real phone needs your computer's LAN address.
Arabic switches the layout to right-to-left.
