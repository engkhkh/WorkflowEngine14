# Workflow ERP - Ionic + Capacitor (Angular)

The full app: workflow tasks, documents, HR, POS, Hospital, Finance, every ERP module, Governance (audit, approvals, period lock, custom fields), VAT / ZATCA, batches and serials.
Same code as `mobile-app`.

    npm install
    npm start                 # browser
    npm run cap:android       # build + open Android Studio (ios: cap:ios)

Set the server in `src/environments/environment.ts` (`10.0.2.2` for the Android emulator).
